# PLANTILLA ASOMBROTECA

Motor reutilizable para explainers verticales con voz. Se puede adaptar a cualquier tema y contexto.

| Archivo o carpeta | Contenido |
|---|---|
| `INSTRUCCIONES_PLANTILLA.md` | Reglas, estructura narrativa, subtítulos, sonido, pieles, bloques, paso a paso y control de calidad. |
| `motor/plantilla.js` | Pieles (`plana` y `oscura`), bloques visuales, subtítulos palabra a palabra con la palabra clave seleccionada, transiciones, efectos de sonido con nombre y generador de `scoreSound` y `scoreMusic`. |
| `lib/` | H y SOUND sin modificar. |
| `fonts/` | Nunito, Fredoka, Space Grotesk, IBM Plex Mono y Fraunces, embebidas, con sus licencias. |
| `tools/` | Transcripción (Whisper), alineación, subtítulos, captura de fotogramas, render, stems y hoja de contacto. |
| `ejemplo/` | Cómo partir del episodio de referencia, `ASOMBROTECA_SUBMARINO_PROYECTO/V3_PLANTILLA/`. |
